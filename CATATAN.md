# Kebiasaan Jelek yang Harus Dihindari Selama Pengembangan
1. Jangan males! Kalau tanya AI jangan terima langsung, biasain check sumber.
2. Lakuin push itu ada langkahnya
> 1. Pertama lakuin ```git add .```
> 2. Kedua commit dan tambahkan message  ```git commit -m "pakai AI aja udh jago"```
> 3. git pull dari sumber
> 4. Selesaikan konflik (jika ada) dan pastikan aplikasi Anda tetap berjalan normal di lokal.
> 5. Terakhir, kirim perubahan Anda ke server utama menggunakan perintah ```git push origin <nama-branch>``` (contoh: `git push origin main` atau `git push origin master`).
